# Data Dictionary

The project uses a reproducible **synthetic retail dataset** generated by `src/generate_data.py`. No AdventureWorks files or external proprietary data are used.

| Column | Type | Meaning |
|---|---|---|
| `date` | Date | Calendar date of observed demand |
| `store_id` | String | Store identifier (`S01`–`S05`) |
| `sku_id` | String | Product identifier (`SKU001`–`SKU020`) |
| `category` | String | Product category |
| `region` | String | Region assigned to each store |
| `price` | Float | Simulated daily selling price |
| `promotion` | Integer | 1 when a promotion is active, otherwise 0 |
| `holiday` | Integer | 1 for selected holiday dates, otherwise 0 |
| `units_sold` | Integer | Observed daily units sold; prediction target |
| `lead_time_days` | Integer | Simulated replenishment lead time in days |

## Dataset size

- 731 calendar days: 2024-01-01 through 2025-12-31
- 5 stores
- 20 SKUs
- 73,100 rows (`731 × 5 × 20`)

## Modeling features

The model adds leakage-safe lag and rolling features (`lag_1`, `lag_7`, `lag_14`, `lag_28`, `rolling_mean_7`, `rolling_mean_28`) plus calendar fields. Rolling values are shifted by one day so the current target is never used as an input.
